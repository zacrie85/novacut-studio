# NOVACUT Studio — File Terbaru

**v1.0.12 (tampilan baru + 2 playlist terpisah + mode sederhana)**

- `NOVACUT-Studio-Setup-1.0.12.exe` — installer per-user, tanpa izin administrator
- `NOVACUT-Studio-Portable-1.0.12.exe` — versi portable, tinggal jalankan

Baru di v1.0.12:
1. Tampilan baru bergaya profesional (seperti CapCut) — warna netral, teks lebih besar & lega, tanpa efek berlebihan
2. Layar sambutan: langsung pilih "Edit Video (Timeline)" atau "Export Langsung & Split"
3. Mode Sederhana — wizard 3 langkah: Pilih Video → Atur → Export (Mode Pro tetap ada, bisa diganti kapan saja)
4. Playlist dipecah jadi 2 menu terpisah: **Playlist Editor** (video untuk timeline) & **Playlist Langsung** (video yang langsung di Export & Split tanpa edit)
5. Urutan video di playlist bisa ditarik (drag) untuk mengubah urutan part
6. Progres export paralel tampil per video — tiap video punya baris progres sendiri (antre / jalan / selesai / gagal)
7. Tombol pintas keyboard: Spasi = putar/jeda, S = potong klip, ← → = maju/mundur (Shift = 5 detik), Del = hapus klip
8. Tooltip bahasa Indonesia di semua tombol ikon
